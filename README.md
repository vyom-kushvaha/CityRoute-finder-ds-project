# City Route Finder

A C++ Data Structures mini project that finds the shortest path between cities using graphs.

## Features
- Add cities and roads with distances
- Display the city network
- Find the shortest route between two cities
- Validate road distances and prevent duplicate roads

## Tech Stack
- Language: C++
- Data Structure: Graph (Adjacency List)
- Algorithm: Dijkstra's Shortest Path Algorithm
